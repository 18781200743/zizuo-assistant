# Zizuo 助手（电脑 + 安卓）

电脑端和安卓端的游戏辅助，直接调用游戏自己的接口，不靠截图找图，窗口拖动/缩放不影响。

- 电脑端：抢红包、祈愿、复活、战斗参数、抽卡、运行命令（等待 / 点击 / 滚轮 / 移动 / 传送 / 回城 / 采集 / 开宝箱）。
- 安卓端：抽卡、同样的运行命令、悬浮球面板、夜间/白天。
- 运行命令参考 `game_storage_sync` 的「自定义指令」，一行一条，`#` 开头是注释。

## 环境

- Windows 10/11
- Python 3.10+（安装时勾选 Add python.exe to PATH）
- Edge WebView2（Win10/11 一般自带）

## 启动

双击 `run.bat`。首次会自动创建虚拟环境并安装依赖。

## Win10 兼容模式

如果点「打开游戏窗口」后一直提示 **9229 调试端口没响应**：

1. 助手会先等 WebView2 约 15 秒；仍没有调试端口，会自动改用 **Edge/Chrome 窗口** 打开游戏（需要系统已安装 Edge 或 Chrome）。
2. 也可以手动强制：在 `config.json` 里加 `"game_window_backend": "edge"`，之后每次都用 Edge 窗口。
3. 兼容模式用的是独立配置目录 `saves/edge-profile`，第一次需要重新登录游戏，之后会记住。
4. 兼容窗口的标题会自动保持为「Zizuo游戏窗」，窗口锁定/截图相关功能仍按这个标题工作。
5. 如果 Edge/Chrome 都没装，点「打开游戏窗口」会提示安装路径；装好后再试即可。

## 发给别人用

1. 双击 `build_release.bat`，在 `dist/` 得到源码 zip 和 exe 包。
2. 把 zip 发给对方；对方解压后看 `分享给别人.txt`。

源码包需对方安装 Python；exe 包免 Python（体积更大）。

## 运行命令

从「辅助工具」→「运行命令」进入，一行一条：

```text
移动(上,1)
等待(0.5)
点击(50,50)
滚轮(下,10)
传送(2,1)
回城()
采集(活动)
开宝箱(1)
```

- 支持 **10 个槽位**：在「分类」里选「我的」管理自己的脚本，点「新建」创建并命名，点「重命名」改名，点「保存」保存内容。运行时可以 `跳转(2)` 跳到另一个槽位继续执行。
- 指令列表按「分类」筛选：全部 / 采集 / 日常 / 其他 / 刷怪 / 我的；名称直接显示脚本名，不再带「同步助手 / 内置」前缀。
- **录制**：点「录制」后在游戏窗口里点击/拖动摇杆/滚轮，助手会生成 `点击(...)` / `移动(角度,秒)` / `滚轮(...)` / `等待(...)`，再点「停止录制」写回当前槽位。
- 传送：`传送(章节,地图)`，可选第三个参数指定大陆，例如 `传送(2,1,1)`。
- 回城：优先走主城地图传送，没反应自动退回营地。
- 采集：和参考工具一样，**只等游戏自己采，不寻路、不瞬移**。通常放在 `移动(...)` 后面，让角色走进采集范围；`采集(活动)` 认活动掉落，`采集(木材)` / `采集(矿石)` / `采集(宝石)` 等按掉落名匹配。5 秒没有新的采集/打怪动作就继续下一步。
- 开宝箱：`开宝箱()` 能开全开；`开宝箱(3)` 最多开 3 个；`开宝箱(1,双倍)` 走双倍领取。
- 状态栏会显示当前执行到哪个槽位、哪一步，以及开箱/采集结果。

## 鼠标瞬移

在「辅助工具」的「取坐标」一栏勾选「鼠标瞬移」，然后在游戏地图上点任意位置，角色会直接闪现过去。

- 避开顶部 HUD 和底部摇杆/按钮区，点地图中间区域；
- 取消勾选或停止辅助即关闭；
- 和「取坐标」互斥：点「取坐标」会自动关闭鼠标瞬移。

## 自动宝箱

在「辅助工具 → 地图刷新」里：

- **自动宝箱**：每 8 秒检查当前地图的 BOSS 掉落宝箱并自动开箱；
- 停止辅助或关闭开关后会停止；自动宝箱会消耗宝箱次数。

## 公会情报

入口：**辅助工具 → 功能玩法 → 公会情报**。

进入「功能玩法」后默认不显示内容，点「公会情报」按钮（按钮会高亮）才会在下方展开查询面板。

- 查询公会战据点（我方 1、敌方 2，各 1~13 号），显示驻守成员、等级、区服和三队总战力；
- 「阵营」可选 全部 / 我方 / 敌方，「全部」大约 5~8 秒查完 26 个据点；
- 选中据点，下方显示成员明细，并自动读取每个成员三个队各自的战力（需要几秒）；点「复制结果」可把全部内容复制到剪贴板；
- 点「全部导出」：自动查询全部据点、读取每个成员的三队战力，导出 CSV（Excel 可直接打开）；
- 战力 100/200/300 是游戏给未配置队伍的占位值，工具会显示成「未配置」，不计入总战力；
- 如果提示公会战服务未加载，先在游戏里打开一次公会/公会战界面再查。

## 公会迷宫

入口：**辅助工具 → 功能玩法 → 公会迷宫**。

- 选中「公会迷宫」后会自动等待首领战斗，进入后约 2 秒内自动记录；也可以手动点「查询首领」；
- 显示首领的难度、层数、编号、总血量、抗暴击、抗暴伤、命中率和全部属性；
- 只读查询，不会发起挑战或修改游戏数据；
- 离开战斗后保留本次结果，刷新页面后清空；
- 点「复制结果」可复制当前显示的首领属性。

## 功能玩法

入口：**辅助工具 → 功能玩法**。

- **跳一跳**：进入游戏「秘境探宝」后，在功能玩法里点「开始自动跳」，自动选力度连续跳。
- **农场**：推荐「自动循环」，自己的菜熟了就回个人农场收菜并补种，没熟就去好友农场偷菜/施肥；每日偷菜、施肥、浇水、除虫次数用完就只等自己的菜。
- 日常任务、护符升级：入口已留，下一步实现。

## 抽卡（常驻招募）

流程：勾选目标英雄 → 开始招募（直连游戏招募接口）→ 出现目标就点最大/招募，没有就刷新/放弃。

1. 「抽卡」页勾选目标英雄 → **开始招募**；再点一次停止。
2. 默认命中后不停止；可勾「命中目标后停止」。结果在 `saves/gacha_result.json`。
3. 抽卡统计（次数 / 红卡 / 消耗 / 绿钻 / 总时间）在页面顶部显示。

卡池：天使、舞姬、缘壹、亚瑟、白无常、甘道夫、吉尔、莉娜、银发、史矛革、卡尔、王子、黑寡妇、德鲁伊、敖丙、酒神、圣骑、李白、卡卡西。

## 游戏辅助（新）

「游戏辅助」页直接调用游戏自己的接口，不是截图找图，所以不受窗口拖动/缩放影响：

- **快速抢红包**：60ms 一轮扫聊天里的红包（世界 / 跨服 / 公会三个频道全扫，每个频道最多 100 条），
  拿到就调原生领取接口，领取间隔 50ms；今日红包数和领到的绿钻（按绿钻余额增量算）
  都记在页面 localStorage 里，刷新页面不清零，**过零点自动归零**；界面只显示**实际领到**的数
  （连上游戏时只认页面计数器，不拿旧文件兜底），每领到一个就在日志里记一行。
  后台节流两道保险：游戏窗口启动时关掉浏览器的定时器节流（`--disable-background-timer-throttling`
  + `--disable-features=IntensiveWakeUpThrottling`），即使参数没生效，Python 每 90ms 还会用 CDP
  直接调页面里的 `__redTick()` —— `Runtime.evaluate` 不走页面定时器，最小化/切后台都不掉速。
- **小怪 / BOSS 死亡后等待 N 秒**：盯住当前地图的怪物，读模型自带的死亡状态（`KFPX.AINJ()`，
  死了会一直是 true；怪死后不会从列表消失，只隐藏节点），判定死亡后等 N 秒，
  再调游戏自己的「进场景」接口重进当前地图，一屏刷新继续刷怪。小怪和 BOSS 分开设时间。
- **BOSS 金币统计**：检测到 BOSS 死亡后开 20 秒结算窗口，窗口内 HUD 金币的增加值算作 BOSS 收益，
  记进「今日 BOSS 金币」，挂机自动到账的零钱不算。
- **祈愿领取**：到点调原生 `领取` 并自动把原英雄放回槽位，剩余时间在页面内倒计时。

用法：**打开界面就自动连接、没有游戏窗会自动打开一个（不用点启动）→ 进入游戏主界面 → 按需开启功能**。
进游戏后没反应就点「重新连接」；关掉界面辅助就停止，不会在后台偷偷跑。
不想让它自动开窗，把 `config.json` 里 `assist.auto_open_window` 改成 `false` 即可。

战斗参数（倍伤 / 视野 / 技能冷却，照参考工具实现，默认关闭）：

- **英雄倍伤**：hook 英雄受伤结算（`JPVU.BMGQ`），只放大**我方英雄**的伤害字段，
  不碰治疗、吸血和怪物共用的配置；倍率 1-70000。
- **视野**：改怪物配置里的初始索敌半径（`MonsterAttribute.QOML`，只动 350/500 两档），
  并把当前地图里对应怪的运行时索敌（`QJVQ.NAYM`）一起改掉；0 = 不让怪发现，1 = 扩大到 1400。
- **技能冷却**：把原始冷却 40~60 秒的技能改成指定毫秒数（参考工具也只改这一档）。
- **和地图刷新互斥**：开着这三项时不能开小怪 / BOSS 重进，要先关掉（参考工具同样要求）。
- 关掉功能会把原值还原；换地图 / 重新加载导致会话变化时会自动停掉并提示重新开启。

快速复活（全灭后自动复活，延迟 0~10 秒可配）：

- **道具复活**：调原生 `yx_fuwu.RZFJ(false)`，等同点面板上的「复活」，消耗复活道具；
- **广告复活**：`RZFJ(true)`，等同「看广告复活」，不消耗道具；
- **回营地复活**：点面板的「放弃/返回」回营地（英雄自动满血），再用 `XIPH` 回到原地图继续刷；
- **回营地并飞回原位**（参考脚本 gohome → goto → fly 的做法）：
  `XIPH(当前地图号)` 原地重进这张图 → 队伍回到地图营地/篝火、阵亡英雄在营地复活 →
  `LFFY.DLMM/JTSZ` 把队伍坐标写回出发位置（不需要回主城，实测重进约 2 秒）；
- 全灭面板（`KYUK`）一出现就开始计时，延迟到点自动执行；今日复活次数显示在状态行。
- 「飞回原位」是直接写队伍坐标（`LFFY` 是游戏自己复活/拉回队伍用的位置接口）；
  地心实测飞 ±4000 停留 8 秒不被服务端拉回，10 个英雄按半径 36 的圈排开。

单英雄复活（死一个，1~2 秒后动手）：

- 每 250ms 扫一遍实体世界，英雄单位（`SLKU()` 为真）一旦 `AINJ()`（已死）就开始计时；
- 四种方式（下拉框选）：
  1. **本地计时复活**：游戏里每个英雄都有复活倒计时 `QJVQ.SGQP`（实测原值 **60 秒**，
     存储字段 `HPJR`）；把它改成 N 秒，游戏自己的重生系统到点就把英雄拉起来。
     这是最接近「点一下然后打 BOSS 就快速复活」的做法，但改的是战斗属性，是否被哈希校验
     需要实测；
  2. **服务器复活（道具）**：发全灭面板「复活」按钮的同一条请求 `yx_fuwu.RZFJ(false, 回调)`；
  3. **服务器复活（广告）**：`RZFJ(true)`，不花道具；
  4. **回营地复活**：`XIPH(当前地图)` 回营地（英雄在营地复活，队伍留在营地）；
- 默认 1 秒，可填 1~60 秒；状态行按阶段显示「正在回营地 / 已回营地 / 已飞回原位」；
- 备注：客户端的重生系统 `NOYR.LBUD(...)` 只改本地，服务端会重新判死，所以不再使用。

关于重进地图：

- 重进用的是游戏自己的「正常重进」接口 `VKXX.XIPH(VKXX.AGDA.POMD)`（参考工具
  `az_dituZhengchangChongjin`），会重新走一遍地图加载，小怪会刷回来。
- 死亡判定看单位模型的 `KFPX.AINJ()`（死了恒为 true），所以 BOSS 不会「从列表消失」也能判出来。
- BOSS 是否立刻复活由服务端计时决定，客户端重进不能强制它刷新。
- 一张图一次死亡只发一次请求，进图后 8 秒内不会重复发，避免连点。
- 一次消失超过 20 个单位会被当成切图/加载，不算击杀，避免误判。
- 「诊断（查字段）」会把模块表、各业务入口、当前怪物（是否 BOSS/是否已死）打进日志，
  游戏版本更新导致某功能开不起来时先看这里。
- 「自测重进」会假装击杀一次 BOSS（不动游戏），用来验证整条链路：正常会看到状态里
  从「3 秒后重进地图」倒数到「重新进入地图」，倒数完回到「监控中」。连这个都没反应，
  说明辅助没连上游戏页，点「重新连接」或重启界面即可。
- 字段名集中在一个地方，游戏改名后改 `config.json` 的 `assist.names` 即可，不用改代码，例如：
  `"names": {"redClaim": "hb_lingqu2"}`。
- BOSS 判定默认看怪物名里的关键字，识别不准就调 `assist.boss_keywords`，或直接用
  `assist.boss_ids` 写怪物编号（诊断日志里能看到编号）。
- 统计落盘在 `saves/assist_stats.json`，页面刷新不会把今日数字清零。
- 温馨提示：辅助有风险，使用须谨慎。

## 建议

- 抽卡直连接口需要游戏窗是助手打开的（带调试端口）。
- 游戏版本更新后，如果运行命令提示「未适配」，先更新 `app/assist_mapping.json` 的字段映射。
- 全局热键无效时用管理员运行；界面按钮始终可用（目前只保留 F9 停止）。
- 辅助有风险，使用须谨慎。
