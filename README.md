# 桌面找图助手

电脑端自动化：游戏窗内录制点击 → 生成脚本代码 → 存入 1-10 存档 → 选档运行。  
另含抽卡：勾选目标卡 → 指定存档连抽 → 找图识别停抽。  
存档格式参考常见脚本工具的 `script.json`（每档一段可复制代码）。

## 环境

- Windows 10/11
- Python 3.10+（安装时勾选 Add python.exe to PATH）
- Edge WebView2（Win10/11 一般自带）

## 启动

双击 `run.bat`。首次会自动创建虚拟环境并安装依赖。

## 发给别人用

1. 把英雄脸和按钮图放进项目里的 `人物图片/`（可从本机旧目录同步）。
2. 双击 `build_release.bat`，在 `dist/` 得到 zip。
3. 把 zip 发给对方；对方解压后看 `分享给别人.txt`。

源码包需对方安装 Python；exe 包免 Python（体积更大）。

## 用法（存档 1-10）

1. 选预设分辨率或手填宽高，点 **打开游戏窗口**。
2. **F6** 在游戏窗内录制 → 再 **F6** 结束，生成脚本代码（并复制到剪贴板）。
3. 左边选存档 **1-10**，点 **保存到选中存档**；或点 **写入存档…** 填编号。
4. 选中要跑的存档，**F8** 单次运行 / **F9** 停止（默认不循环，避免一直占鼠标）。

存档文件：`saves/script.json`。窗口等设置仍在 `config.json`。  
内置游戏窗登录态保存在 `saves/webview/`（已关闭隐私模式，避免每次都要验证码）。  
坐标按**客户区**相对位置录制；回放后会恢复鼠标位置。

### 找图（传送等按钮）

1. 鼠标移到「传送」按钮中心 → 点 **截取模板** → 名称填 `传送`。
2. 脚本里写：`找图点击(传送)`（模板在 `templates/ui/传送.png`）。
3. 比死坐标稳，按钮位置略变也能点到。

### 脚本代码示例

```text
# 游戏录制_153045
# relative=1 size=390x844
找图点击(传送)
等待(0.8)
点击(120,340)
等待(0.52)
右键(200,300)
```

也支持参考脚本那种归一化坐标：`点击(0.64,0.66)`（需带 `size=宽x高` 注释）。

## 抽卡（常驻招募）

流程：**开抽 → 识别台上英雄 → 若是勾选目标则点英雄 +「最大」+ 招募，再继续抽**；无目标则刷新/放弃。

1. 用「截取模板」保存界面按钮到 `templates/ui/`：`招募.png`、`最大.png`、`刷新.png`（可选 `放弃.png`）。
2. 把目标英雄脸小图放到 `templates/cards/`，如 `李白.png`。
3. 「抽卡」页勾选目标英雄 → **开始抽卡**；**F9** 停止。
4. 默认命中后不停止（点最大继续抽）；可勾「命中目标后停止」。结果在 `saves/gacha_result.json`。

卡池：天使、舞姬、缘壹、亚瑟、白无常、甘道夫、吉尔、莉娜、银发、史矛革、卡尔、王子、黑寡妇、德鲁伊、敖丙、酒神、圣骑、李白、卡卡西。

## 游戏辅助（新）

「游戏辅助」页直接调用游戏自己的接口，不是截图找图，所以不受窗口拖动/缩放影响：

- **快速抢红包**：订阅游戏聊天事件，红包一出现就调原生领取，并统计今日绿钻。
- **小怪 / BOSS 死亡后等待 N 秒**：盯住当前地图的怪物，读模型自带的死亡状态（`KFPX.AINJ()`，
  死了会一直是 true；怪死后不会从列表消失，只隐藏节点），判定死亡后等 N 秒，
  再调游戏自己的「进场景」接口重进当前地图，一屏刷新继续刷怪。小怪和 BOSS 分开设时间。
- **BOSS 金币统计**：检测到 BOSS 死亡后开 20 秒结算窗口，窗口内 HUD 金币的增加值算作 BOSS 收益，
  记进「今日 BOSS 金币」，挂机自动到账的零钱不算。
- **祈愿领取**：到点调原生 `领取` 并自动把原英雄放回槽位，剩余时间在页面内倒计时。

用法：**打开界面就自动连接、没有游戏窗会自动打开一个（不用点启动）→ 进入游戏主界面 → 按需开启功能**。
进游戏后没反应就点「重新连接」；关掉界面辅助就停止，不会在后台偷偷跑。
不想让它自动开窗，把 `config.json` 里 `assist.auto_open_window` 改成 `false` 即可。

战斗参数（倍伤 / 视野 / 技能冷却，照参考工具实现，默认关闭）：

- **英雄倍伤**：hook 英雄受伤结算（`JPVU.BMGQ`），只放大**我方英雄**的伤害字段，
  不碰治疗、吸血和怪物共用的配置；倍率 1-70000。
- **视野**：改怪物配置里的初始索敌半径（`MonsterAttribute.QOML`，只动 350/500 两档），
  并把当前地图里对应怪的运行时索敌（`QJVQ.NAYM`）一起改掉；0 = 不让怪发现，1 = 扩大到 1400。
- **技能冷却**：把原始冷却 40~60 秒的技能改成指定毫秒数（参考工具也只改这一档）。
- **和地图刷新互斥**：开着这三项时不能开小怪 / BOSS 重进，要先关掉（参考工具同样要求）。
- 关掉功能会把原值还原；换地图 / 重新加载导致会话变化时会自动停掉并提示重新开启。

快速复活（全灭后自动复活，延迟 0~10 秒可配）：

- **道具复活**：调原生 `yx_fuwu.RZFJ(false)`，等同点面板上的「复活」，消耗复活道具；
- **广告复活**：`RZFJ(true)`，等同「看广告复活」，不消耗道具；
- **回营地复活**：点面板的「放弃/返回」回营地（英雄自动满血），再用 `XIPH` 回到原地图继续刷；
- **回营地并飞回原位**（参考脚本 gohome → goto → fly 的做法）：
  `XIPH(当前地图号)` 原地重进这张图 → 队伍回到地图营地/篝火、阵亡英雄在营地复活 →
  `LFFY.DLMM/JTSZ` 把队伍坐标写回出发位置（不需要回主城，实测重进约 2 秒）；
- 全灭面板（`KYUK`）一出现就开始计时，延迟到点自动执行；今日复活次数显示在状态行。
- 「飞回原位」是直接写队伍坐标（`LFFY` 是游戏自己复活/拉回队伍用的位置接口）；
  地心实测飞 ±4000 停留 8 秒不被服务端拉回，10 个英雄按半径 36 的圈排开。

单英雄复活（死一个，1~2 秒后动手）：

- 每 250ms 扫一遍实体世界，英雄单位（`SLKU()` 为真）一旦 `AINJ()`（已死）就开始计时；
- 四种方式（下拉框选）：
  1. **本地计时复活**：游戏里每个英雄都有复活倒计时 `QJVQ.SGQP`（实测原值 **60 秒**，
     存储字段 `HPJR`）；把它改成 N 秒，游戏自己的重生系统到点就把英雄拉起来。
     这是最接近「点一下然后打 BOSS 就快速复活」的做法，但改的是战斗属性，是否被哈希校验
     需要实测；
  2. **服务器复活（道具）**：发全灭面板「复活」按钮的同一条请求 `yx_fuwu.RZFJ(false, 回调)`；
  3. **服务器复活（广告）**：`RZFJ(true)`，不花道具；
  4. **回营地复活**：`XIPH(当前地图)` 回营地（英雄在营地复活，队伍留在营地）；
- 默认 1 秒，可填 1~60 秒；状态行按阶段显示「正在回营地 / 已回营地 / 已飞回原位」；
- 备注：客户端的重生系统 `NOYR.LBUD(...)` 只改本地，服务端会重新判死，所以不再使用。

关于重进地图：

- 重进用的是游戏自己的「正常重进」接口 `VKXX.XIPH(VKXX.AGDA.POMD)`（参考工具
  `az_dituZhengchangChongjin`），会重新走一遍地图加载，小怪会刷回来。
- 死亡判定看单位模型的 `KFPX.AINJ()`（死了恒为 true），所以 BOSS 不会「从列表消失」也能判出来。
- BOSS 是否立刻复活由服务端计时决定，客户端重进不能强制它刷新。
- 一张图一次死亡只发一次请求，进图后 8 秒内不会重复发，避免连点。
- 一次消失超过 20 个单位会被当成切图/加载，不算击杀，避免误判。
- 「诊断（查字段）」会把模块表、各业务入口、当前怪物（是否 BOSS/是否已死）打进日志，
  游戏版本更新导致某功能开不起来时先看这里。
- 「自测重进」会假装击杀一次 BOSS（不动游戏），用来验证整条链路：正常会看到状态里
  从「3 秒后重进地图」倒数到「重新进入地图」，倒数完回到「监控中」。连这个都没反应，
  说明辅助没连上游戏页，点「重新连接」或重启界面即可。
- 字段名集中在一个地方，游戏改名后改 `config.json` 的 `assist.names` 即可，不用改代码，例如：
  `"names": {"redClaim": "hb_lingqu2"}`。
- BOSS 判定默认看怪物名里的关键字，识别不准就调 `assist.boss_keywords`，或直接用
  `assist.boss_ids` 写怪物编号（诊断日志里能看到编号）。
- 统计落盘在 `saves/assist_stats.json`，页面刷新不会把今日数字清零。
- 温馨提示：辅助有风险，使用须谨慎。

## 建议

- 录制时点在游戏窗口内；改窗口大小后建议重录。
- 抽卡模板尽量截卡脸特征清晰的小图，阈值默认 `0.85`，认不出就略降。
- 全局热键无效时用管理员运行；界面按钮始终可用。
- 鼠标移到屏幕左上角可触发 PyAutoGUI 紧急停止。
