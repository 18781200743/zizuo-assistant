# 紫作助手 · 安卓版（HBuilder 5+ App）

游戏跑在一个独立 webview 里；工具页通过 `evalJS` 把 `RUNTIME_JS` 注入游戏页，
再每 800ms 读一次快照。核心功能（红包/复活/地图刷新/闪现/祈愿/抽卡…）
和 Windows 版共用同一套运行时。

## 目录

```
android_app/
  manifest.json      HBuilder 清单（AppID 需要你自己重新获取）
  index.html         工具界面 + 顶部按钮栏
  js/app.js          开游戏窗口、注入运行时、轮询状态、按钮逻辑
  js/runtime.js      注入到游戏页的运行时（由 app/assist_script.py 生成）
  js/mapping.js      字段映射（4758a）
  js/renames.js      写死名字的对照表（按版本）
```

## 打包步骤（HBuilderX）

1. 下载 **HBuilderX（App 开发版）**，登录 DCloud 账号
2. 菜单 `文件 → 打开目录`，选这个 `android_app` 文件夹
3. 双击 `manifest.json` → **基础配置** → 点「重新获取」拿一个新的 AppID（必做，不然云打包会报 ID 冲突）
4. 不需要 USB 调试：直接 `发行 → 原生App-云打包`
   （手机 USB 只能充电/传文件也没关系，打包是在云端做的）
   - 平台勾 **Android**
   - 证书选「使用公共测试证书」
   - 打包类型选「正式」
6. 打包完成后下载 APK → 用数据线选「文件传输」拷到手机（Download 目录）
   → 手机「文件管理」里点开安装（允许未知来源）

## 第一次打开会发生什么

```
1. 顶部显示「等待游戏加载」
2. 下方是游戏窗口（和电脑版同一个 H5）
3. 用验证码登录
4. 进入游戏主界面后，工具自动注入运行时
5. 顶部变成「已连接 · 4758a · 红包 0 个」
```

## 按钮说明

| 按钮 | 作用 |
|---|---|
| 红包 | 开启/关闭快速抢红包 |
| 复活 | 点一下=自动复活开关；**长按=立即复活一次** |
| 小怪刷新 / BOSS刷新 | 死亡后等 1 秒 / 3 秒重进地图 |
| 怪物/闪现 | 列出附近怪（BOSS 标 ★，带血量和距离），点「过去」瞬移 |
| 清除卡图 | 传送/回城点了没反应时点一下 |

## 如果注入失败

顶部会显示「读不到游戏状态」。把手机的 `运行日志`（HBuilderX 控制台）发出来，
重点看：

```
evalJS 是否返回空
有没有 "plus is not defined"
有没有跨域/安全限制报错
```

## 注意

- 这个版本只是**外壳重写**，游戏逻辑（运行时）和电脑版完全一致
- 游戏更新后，需要重新生成 `js/runtime.js` / `js/mapping.js` / `js/renames.js`
  （电脑版有生成脚本，一条命令的事）
