# 紫作助手 · 安卓版（HBuilder 5+ App）

游戏跑在一个独立 webview 里；工具页通过 `evalJS` 把 `RUNTIME_JS` 注入游戏页，
再每 800ms 读一次快照。核心功能（红包/复活/地图刷新/闪现/祈愿/抽卡…）
和 Windows 版共用同一套运行时。

## 目录

```
android_app/
  manifest.json      HBuilder 清单（AppID 需要你自己重新获取）
  index.html         工具界面 + 顶部按钮栏
  js/app.js          开游戏窗口、注入运行时、轮询状态、按钮逻辑
  js/runtime.js      注入到游戏页的运行时（由 app/assist_script.py 生成）
  js/mapping.js      字段映射（4758a）
  js/renames.js      写死名字的对照表（按版本）
```

## 打包步骤（HBuilderX）

1. 下载 **HBuilderX（App 开发版）**，登录 DCloud 账号
2. 菜单 `文件 → 打开目录`，选这个 `android_app` 文件夹
3. 双击 `manifest.json` → **基础配置** → 点「重新获取」拿一个新的 AppID（必做，不然云打包会报 ID 冲突）
4. 不需要 USB 调试：直接 `发行 → 原生App-云打包`
   （手机 USB 只能充电/传文件也没关系，打包是在云端做的）
   - 平台勾 **Android**
   - 证书选「使用公共测试证书」
   - 打包类型选「正式」
6. 打包完成后下载 APK → 用数据线选「文件传输」拷到手机（Download 目录）
   → 手机「文件管理」里点开安装（允许未知来源）

## 第一次打开会发生什么

```
1. 顶部显示「等待游戏加载」
2. 下方是游戏窗口（和电脑版同一个 H5）
3. 用验证码登录
4. 进入游戏主界面后，工具自动注入运行时
5. 顶部变成「已连接 · 4758a · 红包 0 个」
```

## 按钮说明

| 按钮 | 作用 |
|---|---|
| 红包 | 开启/关闭快速抢红包 |
| 快速复活 | 开启/关闭自动复活；开启后按钮变成「关闭」 |
| 手动复活 | 立即手动复活一次 |
| 清除卡图 | 传送/回城点了没反应时点一下 |
| 小怪刷新 / BOSS刷新 | 死亡后等 1 秒 / 3 秒重进地图 |
| 刷新怪物/闪现 | 和电脑版一样：先刷新怪物，选中一只再点「闪现」；支持方式（瞬移/飞过去）、筛选（全部/BOSS/小怪） |
| 鼠标瞬移 | 在「闪现寻怪」这一行，开启后在游戏画面上点哪里就瞬移到哪里 |
| 自动宝箱 | 每 8 秒检查当前地图的 BOSS 掉落宝箱并自动开箱；会消耗宝箱次数 |
| 功能玩法 → 公会情报 | 查询我方/敌方 1~13 号据点驻守成员与三队总战力；100/200/300 显示为「未配置」 |
| 功能玩法 → 公会迷宫 | 只读查询首领难度、层数、总血量、抗暴击、抗暴伤、命中率和全部属性；进入首领战斗会自动记录 |

## 屏幕常亮 / 防息屏

源码里默认开启屏幕常亮：

- 启动、回到前台时调用 `plus.device.setWakelock(true)`，并且每 30 秒补一次（部分系统会自己清掉唤醒锁）；
- `manifest.json` 已声明 `android.permission.WAKE_LOCK`；
- 只有**正式打包出来的 APK** 才会带上这个权限，HBuilderX 基座运行不一定生效。

个别手机（小米/华为/OPPO/vivo）系统管得更严，再补这几步：

1. 设置 → 显示 → 息屏时间调长（或「永不」）；
2. 设置 → 电池 → 找到本应用，关闭「电池优化 / 智能省电」；
3. 手机管家的「应用启动管理」里允许本应用自启动、后台运行；
4. 挂机时不要手动按电源键锁屏——系统锁屏后游戏一定会暂停，任何应用都绕不过去。

## 如果注入失败

顶部会显示「读不到游戏状态」。把手机的 `运行日志`（HBuilderX 控制台）发出来，
重点看：

```
evalJS 是否返回空
有没有 "plus is not defined"
有没有跨域/安全限制报错
```

## 注意

- 运行时与电脑版同步，当前版本 **145**（公会情报 / 公会迷宫 / 鼠标瞬移 / 自动宝箱 / 跳一跳已加）
- 游戏更新或电脑版运行时改动后，先运行 `python tools/gen_android_assets.py`，
  会重新生成 `js/runtime.js` / `js/mapping.js` / `js/renames.js` / `js/version.js`
  （`version.js` 的脚本版本取自 `app/build_info.py` 的 `APP_VERSION`）
- 生成后用 HBuilderX「发行 → 原生App-云打包」重新出 APK
